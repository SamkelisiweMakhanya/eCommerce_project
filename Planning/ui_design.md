## User Experience

The interface should provide clear navigation between the main areas of the application.

### Buyers

Buyers should be able to:

- Browse products and stores easily.
- View product details before purchasing.
- Add and remove products from their cart.
- See their order total before checkout.
- Complete checkout using a clear form.
- View confirmation and invoice information after placing an order.
- View their previous orders.
- Leave reviews for products they have purchased or viewed.

### Vendors

Vendors should have a dedicated dashboard where they can:

- View their stores.
- Create, edit and delete stores.
- View their products.
- Add, edit and delete products.
- View relevant customer orders.
- Update order status where permitted.

## Forms

Forms should have clear labels and validation messages.

Required fields should be identified clearly, and invalid information should be reported to the user without losing valid information already entered.

## Responsive Design

The interface should be usable on different screen sizes, including desktop, tablet and mobile devices.

## Feedback

The application should provide clear feedback after important actions, such as:

- Successful registration
- Successful login
- Product added to cart
- Successful checkout
- Successful order creation
- Successful review submission
- Validation errors
- Unauthorised access
- Missing products
