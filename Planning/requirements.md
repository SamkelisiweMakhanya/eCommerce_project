**E-Commerce Application Requirements**



**Functional Requirements**



1\. Users must be able to register.

2\. Users must be able to log in and log out.

3\. Users must be able to register as buyers or vendors.

4\. Vendors must be able to create stores.

5\. Vendors must be able to edit and delete their stores.

6\. Vendors must be able to add products.

7\. Vendors must be able to edit and delete their products.

8\. Buyers must be able to view stores.

9\. Buyers must be able to view products.

10\. Buyers must be able to add products to a cart.

11\. Buyers must be able to remove products from their cart.

12\. Buyers must be able to checkout.

13\. The system must generate an invoice.

14\. The invoice must be emailed to the buyer.

15\. Buyers must be able to review products.

16\. Reviews must indicate whether the buyer purchased the product.

17\. Users must be able to reset forgotten passwords.



**Non-functional Requirements**



1\. Passwords must be securely stored.

2\. Users must only access functionality they are authorised to use.

3\. Database information must be protected.

4\. Forms must validate user input.

5\. The application should handle errors gracefully.

6\. The application should use a relational database.

7\. The application should maintain user sessions.
